# Lokang — website v2

Static site (HTML/CSS/JS, no build step). Deploy: push this folder to GitHub → "Import project" on Vercel → Framework: Other → Deploy.

## Media
All photos in `assets/` come from Lokang's own company PDF (factories, installation, ZAM panels, salt‑spray test, stadium projects). Three tiles (school, leisure, club) and the plant-room image are Lokang design renderings and are labelled as such.
To swap any image, replace the file with the same name. A real drone/underwater video can replace the hero photos later.
